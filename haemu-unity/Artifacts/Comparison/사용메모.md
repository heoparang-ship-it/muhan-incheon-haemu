## 동작

1. Assets 아래에서 통신사선 돛 메시·프리팹 후보를 점수화해 나열 (`tut01_포교선_돛후보목록.md`).
2. 있으면 `GenerateAllAndCapture` 를 찾아 호출한다. 없으면 현재 씬의 tut01 포교선에 직접 붙인다.
3. 절차형 `CreateFurledSail` 돛은 끄고 `_절차형_보관` 으로 남긴다.
4. 문화재청 돛을 **균일 스케일만** 써서 기존 돛 높이(없으면 clothDepth 17.60)에 맞춘다.
5. 비교 PNG를 `Artifacts/Comparison/` 에 한글 파일명으로 쓴다.

폐기된 스케일은 코드가 막는다.

- 5× 균일 고정 없음
- 가로만 1.5× 식 비균일 확대 없음

승인된 절차형 수치(폴백·맞춤 기준):  
`halfLength=4.08` `clothDepth=17.60` `lean=7.84` `ripple=1.28`

## CreateFurledSail 에 넣을 선택 한 줄

생성 시점에 바로 문화재청 돛을 쓰려면 `HaemuTutorialBootstrap.Ship.cs` 의 `CreateFurledSail` 맨 위에:

```csharp
if (HaemuKhsSailSource.TryCreate(parent, halfLength, clothDepth, out var khsSail)) return khsSail;
```

없어도 메뉴가 생성 후 교체하므로 이식은 된다.
