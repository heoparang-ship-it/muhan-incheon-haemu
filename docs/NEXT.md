# 여기서부터 진행

이 저장소가 원본이다. 이후 작업은 여기 `main`에 커밋한다.

## 지금 상태

- 1장 로직은 `game/index.html` 한 파일에 닫혀 있다.
- 월드는 코드 드로우. 그림 슬롯만 있음.
- 타이틀·세이브·챕터 선택 없음.
- 드라이브 에셋 폴더는 비어 있음.

## 우선순위

1. 드라이브 공유를 **제한**한 뒤 그림 파일을 `assets/`에 채운다
2. `ASSET_DATA` 주입 — 코드 드로우를 그림으로 교체
3. 타이틀 / 브리핑 / 일시정지
4. 중간 저장 또는 구간 체크포인트 (42분은 웹에서 너무 김)
5. 베일 도주 시 목표 체크와 카피 분리
6. `noKill` 의미 정리 (대원 생존 vs 살상 금지)
7. 단계형 튜토리얼
8. 실플레이로 동선·패스파인딩·조수 검증

## 손대지 말 것 (아직)

- 맵 크기·조수 공식 — 바꾸면 미션 전체가 흔들린다
- 대원 역할 재배치 — 잠입 루프가 역할 분업에 기대고 있다

## 로컬에서 열기

```bash
# 아무 정적 서버
python3 -m http.server 8080 --directory game
# 브라우저에서 game/index.html
```
