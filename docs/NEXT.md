# 여기서부터 진행

이 저장소가 원본이다. 이후 작업은 여기 `main`에 커밋한다.

## 지금 상태

- 1장 로직 + 타이틀 + 저장이 `game/index.html`에 닫혀 있다.
- 월드는 텍스처/스프라이트. 건물은 아직 코드 드로우.
- 드라이브 에셋 폴더는 비어 있었고, 그림은 이 저장소 `game/assets/`가 원본이다.

## 우선순위

1. 건물 body/roof 스프라이트
2. 대원·경비 4방향 걷기 시트
3. 단계형 튜토리얼
4. 성가·종·파도 사운드
5. 실플레이로 동선·패스파인딩·조수 검증

## 손대지 말 것 (아직)

- 맵 크기·조수 공식 — 바꾸면 미션 전체가 흔들린다
- 대원 역할 재배치 — 잠입 루프가 역할 분업에 기대고 있다

## 로컬에서 열기

```bash
python3 -m http.server 8080 --directory game
# game/index.html
```
