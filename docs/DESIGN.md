점수: 증거×7 + 구출비율×20 + 설화×4 + 베일 14/6 + 무경보 12 + noKill 8 + 민간 무사망 8 + 민심×6 − 민간사망×9

- A 조용한 매듭 ≥ 92
- B 반쪽의 구원 ≥ 70
- C 떠내려간 증거 ≥ 48
