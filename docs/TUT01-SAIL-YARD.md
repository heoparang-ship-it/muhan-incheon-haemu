# tut01 포교선 — 돛대 높이 판정

Mac Unity 실측만 계산했다. 이 저장소의 플레이 코드는 바꾸지 않았다. Grok 4.6.

짧은 돛대에 천만 키운 PR #33 쌍(`halfLength=6.40`, `clothDepth=18.00`)은 쓰지 않는다. 큰 lean이 갑판·물을 덮어 로컬에서 기각됐다. 돛대를 올리고 천은 거의 수직으로 내린다.

## 지금 (대표 인상 후, 되돌리지 말 것)

| 항목 | 값 |
|---|---|
| 주갑판 | 20 m × 8 m |
| yardY | deckTop + **14.0 m** |
| 높이비 | **0.70** |
| halfLength / clothDepth | 5.20 / 12.90 |
| lean | 1.20 / 0.85 (작음) |
| hem | ≈ deckTop + 1.05–1.10 |
| 면적 SA | 134 m² |
| SA/D (흘수 1.2 / 1.5 / 1.8 m) | 1.24 / 0.99 / 0.83 |

카메라 방위 45°, 고도 40°. 14 m 수직물은 지면 약 16.7 m를 가린다.

## 판정 — 더 높여야 하는가? **예**

**(a) 원경 시작 카메라.** 배로 읽히는 높이비는 0.8–1.0(16–20 m)이다. 지금 0.70은 그 아래다. 화면 세로 투영(고도 40°)은 14 m → 10.7 m, 18 m → 13.8 m(+29%).

**(b) 추진.** 역사적 작업 범위 SA/D 5–20에 한 장으로 닿지 않는다. 18 m여도 면적 176 m², SA/D 1.62 / 1.30 / 1.08. 높이는 가독성으로 정한다. 20 m(1.0배)까지는 필요 없다.

## 권고 한 쌍

- `yardY = deckTop + 18.0` (높이비 0.90)
- `clothDepth = 16.90` (hem ≈ deckTop + 1.10)
- `halfLength = 5.20` (지금 너비 유지)
- lean 1.20 / 0.85 유지

Heritage `clothDepth=17.60`은 참고 크기이나, 18 m yard에 그대로 쓰면 hem이 너무 낮다. 5× 균일 스케일, lean 8–11 m는 금지.
