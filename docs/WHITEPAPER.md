## 1-1. 좌표계와 카메라

- **2:1 아이소메트릭**. 타일 가로 64px, 세로 32px, 높이 1단위 = 20px.
- 변환 공식: `isoX = (tx−ty)×32`, `isoY = (tx+ty)×16 − 높이×20`. 이 공식 하나를 게임·렌더러·에셋 베이커가 전부 공유합니다.
- 카메라: 확대 0.44~1.8배, 휠 확대·드래그 이동·선택 대원 따라가기(F).
- **적응 해상도**: 1.1초마다 평균 프레임 시간을 재서 내부 해상도를 0.58~1.4배 사이에서 자동 조절. 느린 기기에서는 화질을 낮춰 프레임을 지킵니다.

## 1-2. 맵 — 절차 생성 + 수제 배치 하이브리드

- **96×96 = 9,216칸**. 칸마다 지형(12종)·높이(소수)·구역·은폐도·통행·실내여부·지붕·시야차단높이 8가지 값을 가짐.
- 큰 지형은 수식으로: 대각선 거리 `s = tx+ty` 기준으로 절벽(s<58) → 본토(<110) → 해변(<124) → **갯벌(<166)** → 바다. 백석섬은 원판(중심 74,76 반지름 10.6), 해식동굴은 속이 빈 바위산(중심 86,84 반지름 10.2 — 테두리 높이 2.72, 내부 −0.18, 마른 선반 0.55).
- 정밀한 곳은 좌표를 직접 박음: 건물 35동(초가 17·기와 15·서양식 2·담장 1), 문 14(잠김 5), 등불 18, 소품 210, 상호작용 지점 23.
- `paintRamp`: 절벽 사이에 경사로를 "높이를 직접 칠해서" 뚫는 도구. 계단 턱이 생겨 길이 끊기는 문제를 원천 차단.
- 실내: `addRoom`이 벽·문·실내 바닥·지붕 번호를 함께 기록 → 대원이 들어가면 그 지붕만 사라짐.

## 1-3. 조수 — 이 게임의 발명품 (코만도스에 없음)

- 미션 42분 = 저조 → 만조 **1사이클**. 수위가 −0.34에서 +0.40까지 easeInOut 곡선으로 오름.
- 물 깊이는 계산식 하나: **`깊이 = 수위 − 그 칸의 높이`**. 깊이 0.30 초과 = 통행 불가.
- 그래서 "길을 막는 코드"가 따로 없습니다. 갯길은 높이가 낮아서 만조에 **저절로** 잠기고, 동굴도 저절로 침수됩니다. 수문(sluice)을 열면 동굴 구역만 수위가 −0.28로 강제 배수.
- 안개·시야·조명도 같은 시계에 물려 있음: 안개 0.18→0.73, 경비 시야는 안개만큼 감소.
- 시간이 다 되면 미션 실패("만조가 감나루를 삼켰습니다").

## 1-4. 길찾기 — 직접 구현한 A*

- 8방향 A* + **이진 힙** + 스크래치 배열 재사용(가비지 없음) + 대각선 코너 끼임 방지 + 지형별 이동 비용(닫힌 문 +6 등) + 경로 스무딩(시야가 닿으면 중간점 생략).
- 통행 판정에 조수 깊이·잠긴 문(경비도 대원도 잠긴 문은 못 지남, 안 잠긴 문은 자동 개폐)·경사 한계(0.52)까지 반영.
- 목적지가 막힌 칸이면 `nearestOpen`이 근처 빈 칸을 대신 찾음.

## 1-5. 시야(LOS) — 높이를 아는 광선

- 보는 쪽 **눈높이 = 지면+1.6**, 보이는 쪽 **가슴 = 지면+0.85**. 두 점을 잇는 광선을 거리×2.2개 점으로 샘플링.
- 차단 판정 3종: 벽·건물(`높이+차단높이 > 광선높이`), 닫힌 문(높이 1.5), 언덕(지면이 광선보다 0.12 높으면).
- 결과: **높은 곳에서는 담장 너머가 보이고, 낮은 곳에서는 안 보이는** 지형 우위가 공식 하나로 성립.

## 1-6. 소리 — 지형이 곧 게임플레이

- 지형별 발소리 계수(코드에 있는 값): 갈대 0.40 < 갯벌 0.55 < 풀 0.62 < 모래 0.70 < 염전 0.80 < 흙길 0.85 < 바위 1.00 < 돌 1.15 < 바다 1.30 < 실내 1.35 < 나무 1.45 < 부두 1.50 < **동굴 1.60**.
- `emitNoise`가 소리를 전파하고, 닫힌 문은 소리를 0.72배로 줄임. 들은 경비는 의심 +0.30~0.85.

## 1-7. 경비 AI — 연속 의심 게이지 + 3단 경보

**22명**, 5직군. 직군마다 시야 거리(7.6~11.2칸)·시야각(62°~76°)·속도·경보 방식·변장 간파율이 다름:

| 직군 | 시야 | 경보 방식 | 변장 간파 |
|---|---|---|---|
| 외곽 신도 | 7.6칸 | **직접 발령 못 함** — 상급자에게 달려가 보고 | 0% (완전히 속음) |
| 흰옷 집사 | 8.6칸 | 국지 경보 | 55% + **검문**(말을 걸어 확률 판정) |
| 조선인 사병 | 11.2칸 | 국지 경보 | 20% |
| 외국인 선원 | 9.6칸 | 국지 경보 | **100% (변장 무시)** · 총 소지 |
| 내부 사제 | 8.2칸 | **종을 쳐서 전면 경보** | 80% |

- **의심 게이지**: 보이는 정도(거리·조명·은폐·자세·움직임·변장)에 비례해 초당 0.72(바깥 시야)/1.55(안쪽 시야)/2.6(경보 중) 속도로 참. 0.42 넘으면 조사하러 옴, 1.0에 발각.
- **안쪽/바깥 시야 구분이 이미 코드에 있음**: 시야각 45%·거리 60% 안쪽은 즉시 식별 구역, 바깥은 느리게, 게다가 **정지해 있으면 바깥 시야에서 0.45배로 잘 안 잡힘** — 코만도스의 2존 시야 규칙과 같은 구조(단, 화면 표시는 아직 1겹 → 2부 참조).
- **은폐**: 갈대 등 은폐 지형에서 웅크리면 노출 ×0.30 수준까지 감소. 등불 반경(5.6칸) 안은 반대로 증가.
- **경보 3단**: 0 평시 → 1 국지(26초, 주변 경비 집결) → 2 전면(60초, 전원 시야 ×1.25·각 ×1.3). 시간이 지나면 2→1→0으로 **한 단씩 내려감**.
- **흔적 수사 4종**: 대원 발자국(찍힌 지형에서 26초 유지, 최대 220개), 열린 문(+0.45)/부서진 문(+0.75), 꺼진 등불(+0.42), **쓰러진 동료 발견(즉시 경보+보고)**.
- 그물에 걸린 경비는 일정 시간 묶였다가 풀리면 의심 1.0으로 깨어남. 유인(lured) 상태 별도.

### D11. 사운드 확장

### D12. 미션 통계 화면
결과 모달에 추가: 제압 수/발각 횟수/유인 횟수/이동 거리/증거 타임라인. 이미 상태에 있는 값 집계 위주. (~80줄)

## 3차 — 확장 (에셋 전환과 병행)

- **D13. 2장 프레임**: b_map의 수제 배치를 데이터 객체로 분리(시드+배치표 = 장 1개). 코드 변경 없이 장 추가 가능한 구조로. (~200줄 리팩터)
- **D14. 리플레이 고스트**: 대원 경로 기록 → 결과 화면 미니맵에 재생. (~120줄)
- **D15. 접근성**: 색맹 팔레트(시야콘 색을 무늬로 병행), 키 재배치, UI 배율. (~150줄)

# 4부. 하지 않을 것 (범위 확정)

1. 총격전·살상 시스템 — 정체성 위반. 무살상이 점수 규칙에 박혀 있음.
2. 차량·선박 조종 — 조선 배는 목표물로 충분.
3. 카메라 회전 — 8방향 스프라이트 체계와 상충, 코만도스 1도 고정임.
4. 멀티플레이 — 단일 HTML 오프라인 원칙과 상충.
5. 외부 라이브러리 도입 — 의존성 0 원칙 유지. 모든 개발 항목은 순수 JS로 가능함을 확인하고 설계했음.
